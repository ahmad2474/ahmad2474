## Featured projects

### [OpsPilot AI](https://github.com/ahmad2474/opspilot-ai)
An AI assistant for investigating AWS infrastructure, identifying potential waste, and assessing resource dependencies.

- OpenAI Agents SDK workflows and an authenticated MCP interface backed by shared AWS services.
- 15 resource collectors, seven waste checks, semantic investigation memory, and model-provider fallback.
- Infrastructure inspection uses read-only permissions; application data is stored separately in DynamoDB.
- Evaluation fixtures, Docker deployment configuration, and Terraform for EC2 hosting.

**Python · FastAPI · OpenAI Agents SDK · MCP · AWS · Terraform**

### [InsightLoop](https://github.com/ahmad2474/insightloop) · [Live app](https://insightloop-roan.vercel.app)
A conversational analytics application that explores a synthetic e-commerce dataset in BigQuery.

- An agent inspects the schema, generates SQL, queries data, and asks clarifying questions.
- Streams tool activity with bounded tool rounds, SQL validation, and query timeouts.
- Gemini and Groq integrations, including Gemini thought-signature handling across tool calls.

**TypeScript · Next.js · BigQuery · Gemini · Groq**

### [CloudOps RAG](https://github.com/ahmad2474/cloudops-rag)
A retrieval application for cloud operations documentation, with access-aware search and source citations.

- Hybrid keyword/vector retrieval, reranking, and parent-child context expansion.
- Role-based document filtering, citation validation, and abstention paths.
- A 315-question evaluation dataset and evaluation tooling; AWS infrastructure defined in Terraform.

**Status:** AWS deployment and live benchmarking are pending Amazon Bedrock quota approval. No live benchmark results are claimed.

**Python · FastAPI · Amazon Bedrock · OpenSearch · RAG · Terraform**

### [AI Resume Builder](https://github.com/ahmad2474/ai-resume-builder) · [Live app](https://ai-resume-builder-tau-five.vercel.app)
A conversational resume builder with structured information collection, an editable preview, and five PDF layouts.

**Python · FastAPI · Groq · JavaScript · ReportLab**
